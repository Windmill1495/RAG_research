# 数据来源与许可

本项目 
`data/passages.jsonl` 是 [QReCC passage 公开镜像](https://huggingface.co/datasets/slupart/qrecc-passages/tree/main/data) 中 `train-000.parquet` 的固定前 10,000 条
`data/questions.jsonl` 由 [QReCC 官方测试集](https://zenodo.org/records/5760304) 筛选
原始 QReCC 作者及项目见 [Apple ML-QReCC](https://github.com/apple-aiml-research/ml-qrecc)
该项目说明 QReCC 数据按 **CC BY-SA 3.0 Unported** 发布。本包保留 passage ID 中的原网页 URL，并在 manifest 中给出源文件哈希和转换规则
