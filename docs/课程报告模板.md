## 摘要

多轮问答中的指代和省略会使当前问题难以独立表达检索意图。本文实现基于 QReCC 子集的多轮 RAG 系统，使用 BM25 与 `bge-m3` 混合检索，并在固定可见历史下比较查询构造、重写模型规模和重写方法。本报告实际完成【待填写的实验】。在【待填写的样本范围与配置】上，检索结果为【待实测】，A/B/C 基础改写的词面评分与人工盲评结果为【待实测】。结合【待分析的代表性案例与计算开销】，得出【待填写的结论】。

**关键词**　检索增强生成、多轮对话、问题重写、混合检索

## 1 引言

用一条带指代或省略的 QReCC 追问说明研究动机。展示当前问题、可见历史，以及补全哪些信息后才能独立检索。列出报告实际回答的研究问题。

1. 固定语料和检索器，当前问题、历史拼接和直接重写得到的检索排序有何差异？
2. 固定直接重写策略，更换 Qwen3 模型规模后，检索得分、耗时与回退如何变化？
3. 固定模型和输入，结构化重写及条件修复对独立问题的质量与下游检索有何影响？

## 2 相关工作与项目范围

说明检索增强生成如何使用外部证据，介绍会话问题重写中的指代消解、约束保留与历史噪声。本文的实现范围是本地指令模型、固定段落索引及查询改写评测。引用实际阅读的相关论文，并区分原论文实验与本项目实测。

## 3 方法

### 3.1 段落索引与混合检索

说明原始 QReCC passage 如何保留正文和 ID，BM25 倒排如何按词项匹配排序，`bge-m3` 如何给出向量排名，以及 RRF 如何融合两路结果。按实际代码填写 BM25 与 RRF 参数和候选范围。向量请求按模型窗口处理超长输入，BM25 和证据整理使用保留的原始正文。分别报告首次建索引的开销与索引复用后的检索耗时。

### 3.2 查询构造与重写策略

| 策略 | 当前实现 |
| --- | --- |
| `current` | 直接使用当前问题 |
| `history` | 拼接可见历史和当前问题 |
| A · `rewrite` | 直接输出独立问题，解析并检查格式与约束 |
| B · `structured` | 输出主题、指代对象、独立问题和歧义标记，发现校验问题时最多修复一次 |
| C · `compcqr` | 生成组件、组合多查询检索、融合排名并选择最佳段落 |

说明每组收到的当前问题与历史范围、提示词版本和失败处理。三组均记录模型调用及回退，B 额外记录修复。B 的对照结果反映结构化提示、附加检查和条件修复这一整套流程的效果。C 已接入 CompCQR 适配实现，需报告模型、检索器、组合规则、检索深度、选择候选与截断预算。C 的 ROUGE 只对应基础改写，完整方法效果由最终检索排名和全部计算开销衡量。

### 3.3 问答展示

如果报告包含完整 RAG 案例，说明怎样从 Top-K 段落整理带编号的证据、使用多少上下文字符，以及怎样核对回答的证据来源。正文标明案例使用 `demo` 的 BM25 摘录还是 `ollama` 的模型回答。检索与重写的主结果按各自评测入口汇总。

### 4.3 指标口径

- **Gold Recall@1、@3**。每题前 1 或前 3 名命中的不同正例 ID 数除以该题评测记录中的标注正例数，再按题平均。内置子集使用各题的 `positive_ids`。
- **MRR@3**。每题取前三名中首个正例的倒数名次，未命中计 0，再按题平均。@1 与 @3 来自同一份检索排名。
- **ROUGE-1 F1**。比较最终改写和人工参考的词项重合。完整样本中的硬失败按空输出计零，规则回退使用实际输出评分并单列。人工盲评补充对等义表述与语义正确性的判断。
- **耗时和失败**。分别报告 Query 构造、检索与查询总耗时，注明单位、初始化和模型预热的处理。统计错误、回退以及 B 的修复次数与模型调用次数。检索与重写各用相应分母。
