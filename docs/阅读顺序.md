# 从原项目到研究版本

本版本在原 SimpleRAG 的基础上改造，并参考同学 conversational_rag_v2 的结构化重写思路。没有直接照搬其运行环境或旧模型结果。原检索模块中的中文学习注释保留

原流程仍然成立：读取材料 → 建索引 → 构造 Query → Top-K 检索 → 拼参考资料 → Qwen 回答

QReCC passage 保留原 ID 和完整正文，通用 Markdown 和纯文本语料可按字符切块。Retriever 用同一个 Chunk 类型表示两类检索单元，方便检索、上下文与网页复用。

`Chunk.id` 是内部稳定标识，`Chunk.passage_id` 是与 QReCC 正例标签对应的原 ID。不要将内部哈希 ID 与官方 ID 直接比较。

| 模块 | 改动目的 |
|---|---|
| config.py + configs | 配置 QReCC 语料、索引和默认参数 |
| retrieval.py | 导入完整 JSONL passage，用 RRF 融合 BM25 与 `bge-m3` 向量排名 |
| data.py | 校验样本、角色、多个正例和对话划分；只公开 question/history 给模型 |
| prepare_qrecc.py | 先固定语料、过滤空正文；根据原始会话重建角色，核对 Context |
| rewriters.py | 原三种策略独立出来，增加结构化重写、校验与条件修复 |
| pipeline.py | 编排阶段，保留可见历史、原 passage ID 与重写过程；生成不额外读重写 Query |
| metrics.py | 区分来源文档命中、passage Hit、多正例 Recall、MRR、nDCG 和 ROUGE |
| run_cache.py | 实验身份签名、逐题持久化、匹配配置后恢复 |
| evaluate.py | 对比 Query 策略或重写模型，评估混合检索，记录固定样本上的错误与回退 |
| evaluate_rewrite.py | 主实验入口，同时报告重写质量与下游检索，导出人工盲评材料 |
