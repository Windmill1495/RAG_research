这些都是检查程序是否正确的测试代码，不直接衡量模型回答或重写的质量。
| 文件 | 主要检查什么 |
| --- | --- |
| `test_evaluate.py` | 检索指标计算是否正确，生成失败后是否仍保留检索成绩。 |
| `test_llm.py` | Ollama 请求格式、向量返回格式，以及超时、缺少模型等异常处理。 |
| `test_pipeline.py` | Query 构造、检索、上下文拼接和回答生成能否正确衔接。 |
| `test_profiles.py` | 数据集配置、参数校验、索引路径和模型身份记录是否正确。 |
| `test_research_data_eval.py` | 数据是否泄漏、评分与错误统计是否正确，以及盲评样本是否一致。 |
| `test_research_pipeline.py` | 各策略是否使用相同历史，原始段落 ID 是否保留，回答提示是否公平一致。 |
| `test_retrieval.py` | 分词、切块、索引缓存，以及 BM25、向量和混合检索是否正确。 |
| `test_rewrite_data.py` | 重写数据加载、历史构造、语料覆盖检查及重写后的检索评测是否正确。 |
| `test_rewriters.py` | A/B 重写、输出解析、约束检查、条件修复和失败回退是否正确。 |
| `test_run_cache.py` | 实验断点续跑是否可靠，能否避免重复运行和混用不同实验结果。 |
| `test_web.py` | 网页和 API 是否正常，A/B 页面是否可用，以及索引构建是否阻塞网页。 |
